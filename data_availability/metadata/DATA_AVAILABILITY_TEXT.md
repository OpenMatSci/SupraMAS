# Data Availability

The current supporting-data package is available at https://doi.org/10.57967/hf/8671 under `SupraMAS_Supporting_Data/`, with an equivalent ZIP archive. It contains automatic-evaluation inputs and labels, final judge records, statistical analyses, expert ratings, released knowledge entries, generated protocols, the Chain 3 traceback summary, and reported process and superconducting-property summaries.

The GitHub release at https://github.com/OpenMatSci/SupraMAS includes selected current results and the original experimental curve and image exports under `data_availability/source_data/figure_source_data/`. Those exports retain their original measurement filenames and are not part of the current Hugging Face package. The reported Tc summaries do not include individual-film values or standard deviations.

See the [repository path index](../../docs/data_availability.md#github-and-hugging-face-paths) for the correspondence between the two releases.
